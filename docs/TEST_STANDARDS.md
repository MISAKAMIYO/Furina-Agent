## 3. 性能测试标准

| 指标 | 目标值 | 测试方法 |
|------|--------|----------|
| 设置保存响应时间 | < 500ms | 点击保存到收到成功响应 |
| 设置加载响应时间 | < 500ms | 打开设置弹窗到数据填充完成 |
| TTS 合成响应时间 | < 5s (Edge TTS) | 从点击合成到音频开始播放 |
| 滑块响应延迟 | < 50ms | 拖动滑块到数值显示更新 |
| 标签页切换延迟 | < 100ms | 点击标签切换到内容显示 |
| 内存占用 | < 200MB | 正常运行后任务管理器查看 |
| CPU 使用率 | < 30% (空闲时) | 正常运行后任务管理器查看 |

## 5. 测试流程

### 5.1 设置功能测试

1. 打开设置弹窗，切换各标签页
2. 修改各项配置并保存
3. 刷新页面，确认配置已持久化
4. 测试 API 功能是否使用新配置

### 5.2 TTS 功能测试

1. 打开 TTS 设置弹窗，切换各标签页
2. 修改引擎和语音配置并保存
3. 在预览标签页输入文本测试合成
4. 在聊天界面测试自动 TTS 功能
5. 测试各情绪预设对合成效果的影响

### 5.3 对比测试

1. 在 ZhiYan 软件中执行相同操作
2. 对比两者的功能完整性、响应速度、输出质量
3. 记录差异项并评估是否可接受

## 7. 验收标准

- 所有功能测试项通过率 ≥ 90%
- 无 P0 (阻塞性) 问题
- P1 (严重) 问题 ≤ 3 个
- 性能指标全部达标
- 用户体验评分 ≥ 4/5
